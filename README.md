# Nebula Docs

Welcome to the documentation and dev journal for **NebulaFS** — a distributed, versioned file system with built-in Raft consensus, WASM runtime for smart validation, and peer-to-peer networking.

This repo captures:

- 📓 Daily development notes and learnings
- 🧠 Architectural decisions and trade-offs
- 📚 Summaries of papers, protocols, and references
- 🛠️ System design breakdowns and implementation logs
